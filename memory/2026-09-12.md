
## 11:31 qwen 插件彻底移除(用户要求)
- 背景:9/8 尝试接入千问(Standard 中国区),配置了 provider + auth profile 但认证失败(Key 未成功存入)。9/12 用户决定暂不用 qwen,并要求彻底移除。
- 执行:
  1. 备份配置 -> openclaw.json.bak-qwenremove
  2. model.primary 切回 deepseek/deepseek-v4-flash;从 modelPolicy.allow 移除 qwen
  3. 删除 models.providers.qwen 整块(baseUrl=https://dashscope.aliyuncs.com/compatible-mode/v1 + 模型目录)
  4. 删除 auth.profiles.qwen:manual
  5. openclaw plugins uninstall qwen --force(卸载插件,含安装记录与目录)
  6. 清理卸载后残留的 plugins.entries.qwen{enabled:false}
- 验证:openclaw.json JSON 有效、qwen 引用 0 处;plugins list 无 qwen;默认主模型 deepseek/deepseek-v4-flash;gateway 已重启(2026.9.4)。
- 教训:给 openclaw 接第三方 provider 不能只存 Key(paste-api-key),必须同时写入 models.providers.<id> 的 baseUrl+模型目录,且端点/套餐要和 Key 类型匹配(qwen 插件默认国际 Coding Plan 端点,中国区 Standard Key 不匹配)。正确路径是 onboard --auth-choice qwen-standard-api-key-cn 一类,而不是手工分步。
- 遗留:deepseek 插件版本漂移(旧 2026.7.1 -> 期望跟随核心 2026.9.x)未处理;另有多个 multi-agent 配置警告(heartbeat/talk/cron 无 owner)未处理。
