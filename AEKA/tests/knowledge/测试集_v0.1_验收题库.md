# AEKA 测试集 v0.1 —— 验收题库（2026-10-10）

用途：验证 AEKA 的「检索命中 → 引用准确 → 可信度标注 → 不编造」四项能力。
每条含：问题 / 期望依据 / 关键校验点 / 题型标签。

题型标签：
- `规范问答` 需检索规范条款并引用
- `计算`     需调用 engineering_calculator.py
- `拒答`     库内无依据，须明确说"不知道/无依据"，并给出可信度 C/D 或建议渠道
- `版本`     需识别版本状态（现行/被代替）并警示
- `回归`     来自真实对话，用于防退化

| C01 | 200 路 4 Mbps 摄像机保存 90 天，需要多少存储？ | `storage` | 43.2 GB/路·天；总量 777,600 GB（≈777.6 TB）；过程与结论都要给 |
| C02 | 上题若 16 TB 硬盘、RAID5，需要几块盘？ | `storage --disk-tb 16 --raid 5` | 777,600 GB ÷ 16 TB = 48.6 → **取整 49 块**（若计入 1.05 开销则约 52 块）+ RAID5 组阵说明 |

| C05 | 10 km 光纤、0/−24 dBm、2 连接器、4 熔接，链路是否可行？ | `fiber` | 预算 24 dB、衰减 7.9 dB、**余 16.1 dB 满足** |

## 记分口径

| 维度 | 判定 |
|---|---|
| 检索命中 | 是否找到正确标准+条款（页级） |
| 引用准确 | 条款号、数值、标准号是否与原文件一致 |
| 可信度标注 | 是否区分 A/B/C/D；推导是否标 B、经验是否标 C |
| 拒答纪律 | 库内无依据时是否明确说明（**不得编造**） |
| 计算正确 | 过程可复核、结果与工具一致 |
| 版本意识 | 是否正确标注现行/被代替 |

**合格线（建议）**：引用准确率 ≥95%；拒答题 100% 不编造；计算题 100% 过程可复核。
