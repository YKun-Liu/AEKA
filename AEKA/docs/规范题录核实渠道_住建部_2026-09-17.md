# 工程建设类国标题录核实渠道（住建部）——实测 2026-09-17

## 用途
核实 GB 50xxx / GB/T 50xxx（工程建设类国家标准）的**标准号、名称、发布/实施日期、代替与废止关系**。
（市监总局 openstd 全文公开系统**不含**此类标准，std.samr.gov.cn 检索也不命中，必须走住建部渠道。）

## 渠道一：住建部门户站内检索 API（推荐，可脚本化）

```
GET https://www.mohurd.gov.cn/api-gateway/jpaas-jsearch-web-server/interface/search/info_new
    ?websiteid=&q=<URL编码的关键词>&pg=10
    &cateid=6ca0f12c0f0642ab8b1dc17028e12ea1
    &serviceId=e2f3058e2a3b4f8abc93eb76e739e3e7
    &p=1&pos=title,content,filenumber,documentNumber&sortType=2
```

- 返回 JSON：`data.searchResult.result[].data`，含 `title` / `filenumber`（公告文号）/ `content`（公告原文）/ `createdate` / `attachFile`（附件，**部分公告带标准全文 PDF**）
- 关键词可用**标准号**（如 `GB 50394-2007`）或**标准名称**（如 `综合布线系统工程设计规范`）
- 现成工具：`tools/verify_std_mohurd.py "GB 50311-2016" ...` → 输出 `data/verify_report_mohurd.txt`

### 注意事项
- 用标准号检索时，命中的可能是**引用该标准的其他公告**（如通用规范废止强条清单）——同样有核实价值，但要看公告正文语境。
- 按名称检索命中的是发布公告，信息最直接（编号/实施日期/代替关系）。
- 程序化调用时 URL 含 `&`，在 PowerShell 命令行会拆参数 → 用 Python 脚本或 web_fetch 工具调用。

## 渠道二：住建部"标准公告"栏目

`https://www.mohurd.gov.cn/gongkai/fdzdgknr/bzgg/index.html`（JS 渲染，需浏览器）

## 渠道三：行业标准（GA/T、SJ/T、YD/T、MH/T 等）

`https://hbba.sacinfo.org.cn/`（行业标准信息服务平台，可达；检索接口待实测）

## 实测要点（2026-09-17）

1. **强制性通用规范体系（GB 55xxx）影响重大**：2022 年起陆续实施的通用规范**废止了旧标准的部分或全部强制性条文**。
   例：GB 55029-2022（公告2022年第48号）废止 GB 50348-2018 / GB 50394-2007 / GB 50395-2007 / GB 50396-2007 的部分强条；
   GB 55024-2022（第50号）废止 GB 50303-2015 等；GB 55037-2022（第189号）废止 GB 50016-2014(2018年版) 大量强条。
   → **引用旧标准强条前必须核对对应通用规范**。
2. **全文获取**：公告的 `attachFile` 字段有时直接给标准 PDF（如 GB 55029-2022 公告附 5.06MB 全文），是工程建设类国标全文的合法渠道之一。
3. **题录可能过期**：实测发现 GB 50526-2010 已被 GB/T 50526-2021 代替 —— 候选清单必须定期复核。
