# openstd.samr.gov.cn 国标全文自动获取 —— 实测链路（2026-09-07）

> 对象：国家标准全文公开系统 openstd.samr.gov.cn（推荐性/强制性国标在线预览）。
> 结论：**该站无直接 PDF 下载**。全文以"瓦片乱序图片"形式存在于在线预览页，可自动抓取并按页面布局重组还原，再 OCR 成文本。

## 一、关键接口与机制（2026-09-07 实测）

| 步骤 | 接口 | 说明 |
|---|---|---|
| 1. 检索 | `GET /bzgk/std/std_list?p.p2=<标准号>&p.p1=0&p.p90=circulation_date&p.p91=desc` | 匿名可用；返回列表页 HTML，行内含 `hcno` |
| 2. 详情 | `GET /bzgk/std/newGbInfo?hcno=<hcno>` | 匿名可用；题录（号/名称/日期/归口），以及"在线预览/下载"按钮 |
| 3. 预览页 | `GET /bzgk/std/showGb?type=online&hcno=<hcno>&request_locale=zh` | 匿名可用（实测）；返回 **完整预览 HTML**：含全部 page div，每个 div 有 `bg=<文件名>` 属性 + 若干 `<span class="pdfImg-列-行" style="background-position: -Xpx -Ypx">` |
| 4. 取图 | `GET /bzgk/std/viewGbImg?fileName=<bg>` | **必须**：会话 Cookie `JSESSIONID` + 请求头 `Cache-Alive: chunked`；302 → `/bzgk/data/<标准>/<尺寸-序号_随机>.webp` |
| 5. 静态图 | `GET /bzgk/data/...` | nginx 防盗链：无浏览器同源上下文/无 `Cache-Alive: chunked` 头时返回 **200 空流**（伪装的空响应）；curl 需带全头（UA/Referer/Cookie/Accept-Language/Sec-Fetch-*）才能过 |
| 6. 下载/验证码 | `showGb?type=download` | **死代码**：HTML 内 `download()` 的 `isValid` 硬编码 `'true'` → 直接跳 `viewGb`；验证码 modal 永不触发。viewGb 匿名返回空壳 |
| 7. 在线预览阅读 | `viewGb?hcno=` | 空壳页（服务端渲染占位），正文全在 showGb?type=online 那套瓦片机制里 |

## 二、瓦片重组算法

- 每张 webp = 一堵"瓦片墙"，瓦片尺寸 **232×328 px**，宽固定 2320（10 列），高不定（328 的整数倍行数）。
- 预览 HTML 中每个页面 div：
  - `style="width:2315px;height:3274px"`（≈10×10 瓦片网格，1 页 ≈ 2320×3280）
  - `bg="<加密文件名>"`：该页内容取自哪张墙图（**多页共墙**，如 img_04 供 5 页用）
  - 每个 `<span class="pdfImg-C-R">`：C=列、R=行（页内网格坐标）
  - `background-position: -Xpx -Ypx`：内容瓦片在墙图中的原点（x=X, y=Y）
- 重建 = 对每页：新建 2320×3280 白图 → 逐个 span 从墙图 `crop(X, Y, X+232, Y+328)` → `paste` 到 `(C*232, R*328)`。
- 参考实现：`data/rebuild_all.py`（一次性脚本，产物在 `data/gbt28181_rebuilt/`）。

## 三、OCR 成文本

- Windows.Media.Ocr（系统自带，中文包已装）：**输入图宽需 ≤ ~2600px**，把 2320 宽页缩放到 1600 宽再识别（PIL LANCZOS）。
- 产物为逐字空格分离文本（OCR 特性），检索用 OK；阅读建议用"清洗版"（去 CJK 字间空格），脚本：`data/clean_ocr_text.py`。
- 注意：OCR 对数字/字母 `1/I/l`、全半角标点偶有误读；**正式引用条款前需对照页面图**。

## 四、入库规范（对齐 MH/T 7003 既有格式）

- 分类目录：`knowledge/01_国家标准/`（GB 系）；`02_民航标准/`（MH/T 系）
- 文件名：`<标准号空格>_<中文名>_<标准号下划线>.txt` 风格参照既有条目：`GB_T 28181-2022_公共安全视频监控联网系统信息传输交换控制技术要求.txt`
- 分页标记：`===== 第 N 页 / 共 M 页 =====`（与 MH/T 7003 入库文本一致）
- metadata.json 字段：std_no / std_name / std_name_en / standard_type / ics / ccs / publisher / issue_date / implement_date / replaces / supersedes_history / proposer / admin_dept / drafting_unit / status / kb_category / source / quality_note / ingest_date / raw_file / processed_file / pages / remark
- **source 与 quality_note 必填**：区分"用户提供人工确认"与"自动抓取 OCR"，标注 OCR 局限
