AEKA — 民航弱电工程知识 Agent
面向机场弱电工程的规范检索与工程计算助手，每条结论都可追溯到具体条款。

解决什么问题
机场弱电工程涉及规范密集、版本更新频繁、责任重大。工程师的日常困扰是：在几百页 PDF 中翻查具体条例费时费力；不确定所引条款是否已被新版代替；做计算时公式正确，但参数取值没有把握；拿到几百页技术规范书，不知从何读起。

三项核心能力
1. 规范检索：精确到条款号

支持按条款号反查并直接定位原文；检索结果会自动标注版本状态，包括现行、已被代替或强条废止。

2. 工程计算：给出推导过程

包含存储容量、网络带宽、光纤链路、UPS 与电池、机柜负载等模块。每个结果都注明所依据的规范条款，而不只是给出数字。

3. 文档解析：把厚文件变成结构化知识

采用本地规则测绘，零模型成本，通过语义过滤纠错，提取接口、边界等内容。

四级可信度体系
级别	含义
A	规范明文条款，可直接引用（附条款号、页码）
B	基于条文的推导，标注推导过程
C	工程经验、项目资料，明确标注非规范
D	推测，明确说明不确定
纪律：库内无依据时直接说明不知道；不编造条款号和数值；发现冲突时列出冲突并说明取舍理由。
